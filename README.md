# eth-ts-x.github.io

Personal website for Ethan Tsang, built as a simple static GitHub Pages site for job-search and professional introduction.

## Structure

- `index.html` — main one-page site
- `styles.css` — layout and visual styling
- `script.js` — small UI enhancements
- `ResumeYiZeng.pdf` — downloadable resume

## Updating content

- Edit hero, about, strengths, and contact copy in `index.html`
- Adjust colors, spacing, or responsive layout in `styles.css`
- Keep `ResumeYiZeng.pdf` updated so the resume link always points to the latest version

## Deployment

This repository is intended to be served directly by GitHub Pages from the repository root.
